# java-lotto-precourse

1.  로또 구입 금액 입력 받기
2.  구입 금액 유효성 검증 (1,000원 단위, 숫자)
3.  구입 금액만큼 로또 발급
4.  로또 번호 6개 유효성 검증 (Lotto 클래스)
5.  로또 번호 1~45 범위 검증 (Lotto 클래스)
6.  로또 번호 중복 검증 (Lotto 클래스)
7.  발급된 로또 수량 출력 (N개를 구매했습니다.)
8.  발급된 로또 목록 출력 (오름차순 정렬)
9.  당첨 번호 입력 받기 (쉼표 구분)
10. 당첨 번호 유효성 검증 (6개, 1-45, 중복 없음)
11. 보너스 번호 입력 받기
12. 보너스 번호 유효성 검증 (1-45, 당첨 번호와 중복 없음)
13. 당첨 등수(Rank) Enum 구현
14. 구매한 로또와 당첨 번호를 비교하여 등수 계산
15. 당첨 통계 집계 (등수별 개수)
16. 총 수익률 계산 (소수점 둘째 자리 반올림)
17. 당첨 통계 출력
18. 총 수익률 출력
19. Lotto 클래스 테스트
20. 각 기능별 비즈니스 로직 테스트
